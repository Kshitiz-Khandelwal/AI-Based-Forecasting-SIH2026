# Burst-Length vs Window-Size Analysis

**Dataset**: CTU-13 (`data/ctu13_multistage_flows.csv`)
**Window size used in GRU training**: `seq_len = 10`

## Purpose

The GRU labels each 10-step window using the label of the LAST flow after
the window (next-step prediction). If a Reconnaissance or C2 burst is only
3-8 flows long, most windows straddling that burst will contain mostly-Benign
context flows. The final hidden state can be pulled toward BENIGN even when
the labeled flow is genuinely anomalous — this is the **window/burst dilution hypothesis**.

The flat Logistic Regression has no such dilution: it sees only one flow at a time.

### Key Findings
1. **Window-Dilution Hypothesis Confirmed**: Next-step labeling with `seq_len=10` caused majority-class collapse because 83.1% of Recon and 80.0% of C2 runs finished within 2 flows, leaving the target label as BENIGN.
2. **Majority-Vote + seq_len=5 Decisively Outperforms Baseline**: Moving to `seq_len=5` with majority-vote labeling raised Weighted F1 from 68.91% to **88.33%**, beating the Logistic Regression baseline (85.18%) by **+3.15%**.
3. **Zero False Alarm Rate**: The GRU achieved **0.0000% Benign FPR** (0 false alarms out of 4,867 benign test sequences), compared to **7.3351% FPR** for Logistic Regression (which generated hundreds of false alarms).
4. **Data Partition Reality for Recon / C2**: In the CTU-13 chronological 70/15/15 split, the training set contains only 52 Recon flows and 12 C2 flows out of 58,104 flows. Both the sequence GRU and the static Logistic Regression baseline suffer collapse on C2 (LR had 0.00% recall as well, predicting 95.8% as BENIGN). Supplementing with UNSW-NB15/CIC-IDS multi-stage captures will address the raw training support gap for Recon and C2 in future work.
